# Calculadora de Teorema de Pitágoras 📐📱

Aplicación móvil para Android desarrollada en Java/Kotlin orientada a resolver problemas geométricos mediante el Teorema de Pitágoras. La app permite ingresar los valores de dos catetos ($a$ y $b$) para calcular de forma automática, precisa e inmediata la longitud de la hipotenusa ($c$).

---

## 🚀 Características Principales

- **Cálculo Preciso:** Calcula la hipotenusa aplicando la fórmula fundamental:
  $$c = \sqrt{a^2 + b^2}$$
- **Interfaz Intuitiva y Moderna:** Diseñada bajo los lineamientos de Material Design para ofrecer una experiencia de usuario fluida, limpia y fácil de usar.
- **Validación de Entradas:** Controla errores de campos vacíos o valores inválidos (números negativos o ceros) para evitar fallos en el cálculo.
- **Resultados Claros:** Muestra el procedimiento de manera clara en pantalla.

## ⚙️ Instalación y Configuración

1. **Clonar el repositorio** o descargar el código fuente en tu máquina local.
2. Abrir **Android Studio**.
3. Seleccionar **"Open an Existing Project"** y elegir la carpeta del proyecto.
4. Sincronizar el proyecto con Gradle (`Sync Project with Gradle Files`).
5. Conectar un dispositivo físico con depuración USB habilitada o iniciar un **Emulador Android** (AVD).
6. Presionar el botón **Run ▶️** para compilar e instalar la aplicación.

---

## 📱 Uso de la Aplicación

1. Abre la aplicación en tu dispositivo Android.
2. Introduce el valor del **Cateto A** en el campo correspondiente.
3. Introduce el valor del **Cateto B** en el campo correspondiente.
4. Presiona el botón de **Calcular**.
5. Visualiza el resultado de la **Hipotenusa** de forma inmediata.
